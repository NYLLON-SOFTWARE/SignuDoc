# Traceability matrix

Each requirement in [Requirements](requirements.md), where SignuDoc meets it, and how it is tested. Paths are relative to the repository root.

Three kinds of test evidence back the matrix:

- **Automated tests**, which run on every pull request and every push to `main` (see [Release and change control](change-control.md)):
  - `npm test`: unit tests;
  - `npm run test:db`: database tests against a real Postgres;
  - `npm run test:e2e`: a browser test of the whole product.
- **OQ scripts**, which a person runs on your own install: [Operational qualification](operational-qualification.md).
- **Procedures**, for requirements the software can't meet: [Procedures](procedures.md).
